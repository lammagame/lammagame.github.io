# موقع لمّة على GitHub Pages (مجاني)

هذا المجلد موقع جاهز: اللعبة نفسها بالصفحة الرئيسية، وصفحة الدعم، وسياسة الخصوصية.
يتحدّث تلقائياً كل ما تشغّل `npm run build`.

| الملف | شنو هو |
| --- | --- |
| `index.html` | اللعبة (بدون إعلانات ولا شراء، هذني بالتطبيق فقط) |
| `support.html` | صفحة الدعم والتواصل |
| `privacy.html` | سياسة الخصوصية |
| `w/` | صفحة كلمة «ولا كلمة» (اختياري) |
| `manifest.webmanifest` والأيقونات | حتى تنضاف اللعبة للشاشة الرئيسية بالتلفون مثل تطبيق |
| `og.png` | الصورة اللي تطلع لما ينرسل الرابط بواتساب وغيره |

## الرفع (مرة وحدة)
1. ادخل github.com بحساب التطبيق، واضغط **New repository**.
   - إذا سمّيته `اسم-المستخدم.github.io` (بالضبط مثل اسم حسابك)، يصير الرابط `https://اسم-المستخدم.github.io/`
   - أو سمّه `lamma` ويصير الرابط `https://اسم-المستخدم.github.io/lamma/`
   - خليه **Public**.
2. داخل المستودع: **Add file ← Upload files**، واسحب **كل محتويات** مجلد `site` (مو المجلد نفسه)، ثم **Commit changes**.
3. **Settings ← Pages**: بـ Source اختر **Deploy from a branch**، والفرع **main** والمجلد **/(root)**، ثم **Save**.
4. بعد دقيقة أو دقيقتين يفتح موقعك:
   - اللعبة: الرابط الرئيسي
   - الدعم: `.../support.html`
   - الخصوصية: `.../privacy.html`

## بعد الرفع
- حط رابطي الدعم والخصوصية في `src/config.js` (`links.support` و`links.privacy`) وشغّل `npm run sync`.
- وحطهم في App Store Connect و Google Play Console.
- لما تنزل التطبيقات بالمتاجر، حط روابطها في `src/config.js` (`links.appStore` و`links.playStore`) حتى يطلع زر «حمّل التطبيق» بالموقع.

## تحديث الموقع
بعد أي تعديل: `npm run build`، ثم ارفع الملفات المتغيرة بنفس الطريقة (Upload files يستبدلها).
